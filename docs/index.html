Install in a minute

Download

  1. Grab the zip from the latest release and unzip it.
  2. Drag Jotter.app into /Applications.
  3. First launch: right-click → Open. (The app is signed ad-hoc, not notarized, so Gatekeeper asks once.)
xattr -d com.apple.quarantine /Applications/Jotter.app

Prefer the terminal? That clears the Gatekeeper prompt instead.

Build from source

  1. All you need is the Xcode command-line tools.
  2. The whole app is one Swift file; the script compiles, packages, signs, and installs it.
git clone https://github.com/ryanchankh/Jotter && cd Jotter && ./build-app.sh

Yes, the Copy buttons on this page work. It would be strange if a clipboard manager's website made you select text.

Private by construction, not by policy. Jotter has no network code to audit — the entire app is one readable Swift file. Your history lives in plain JSON and PNG files in a folder you choose, and stays there until you delete it.
